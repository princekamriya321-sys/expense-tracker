# Expense Tracker 💰

A full-stack Expense Tracker web application built using Node.js, Express.js, MongoDB, and EJS. It helps users manage their personal expenses, track spending, and analyze their financial activity.

## ✨ Features

- User registration and login
- Secure password hashing using bcrypt
- Session-based authentication
- Add, edit, and delete expenses
- Category-based expense filtering
- Dashboard with expense summaries
- Monthly expense tracking
- Average expense calculation
- Expense visualization using charts
- User-specific expense management

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, EJS, Chart.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas, Mongoose
- **Authentication:** Express Session, bcrypt
- **Other Tools:** Git, GitHub

## ⚙️ Installation and Setup

1. Clone the repository:
   
   git clone https://github.com/princekamriya321-sys/expense-tracker.git

3. Navigate into the project:


   cd expense-tracker
   

4. Install dependencies:

  
   npm install


5. Create a `.env` file in the root directory:


   MONGO_URI=your_mongodb_connection_string
   SESSION_SECRET=your_session_secret
   

6. Start the application:

   npm run dev
   

7. Open your browser at `http://localhost:3000`.

## 🔐 Environment Variables

| Variable | Description |
|---|---|
| MONGO_URI | MongoDB connection string |
| SESSION_SECRET | Secret used for session security |
